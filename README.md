# ConnectIQ website

Static marketing site for ConnectIQ — manufacturing memory and secure device activation.

```
index.html            homepage
fdm.html              FDM Quality page
assets/css/global.css styles shared by both pages (colours, nav, buttons, footer)
assets/js/global.js   behaviour shared by both pages (mobile nav, scroll bar, in-page links)
assets/logo*.png      logos and favicon
```

No build step. Open `index.html` directly, or serve the folder:

```
npx serve .
```
